# Meeting Minutes

Read the raw notes, then write MINUTES.md with exactly these sections:

## 참석자

Attendee names, one per line.

## 결정 사항

Decisions made, one bullet per decision.

## 액션 아이템

Follow-ups in the form "- 내용 (담당: 이름)".

Rules:

- Never invent attendees or decisions missing from the source.
- Keep the file under 60 lines.
