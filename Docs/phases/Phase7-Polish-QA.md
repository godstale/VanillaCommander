## P7-06. 수동 QA 시나리오 실행

- **소유 파일**: `Docs/QA-Checklist.md`(신규 작성)
- **작업 내용**: 아래 골든 패스 + 엣지 케이스를 문서화하고 실제로 실행해 결과를 기록한다.
  - 최초 실행 → 워크스페이스 폴더 선택 → **신뢰 확인 다이얼로그** → 기본 Agent로 채팅 시작 → 정상 응답
  - 파일 탐색기에서 파일 생성/편집/삭제
  - Agent 생성 → 다른 시스템 프롬프트로 응답 차이 확인
  - `AGENTS.md`를 워크스페이스와 상위 폴더 양쪽에 두고 → 두 지침이 모두 반영되는지 확인
  - 스킬 활성화 → LLM이 `<available_skills>`를 보고 `read` 도구로 `SKILL.md`를 로드 → 지침대로 동작
  - `/skill:name` 명시 호출 동작
  - 컨텍스트 임계값 초과 → 자동 압축 → **압축 후에도 원본 대화가 스크롤로 보이는지** 확인
  - 파일 쓰기 요청 → 승인 다이얼로그 → 승인/거절 각각 정상 동작, 거절 시 모델이 대안 제시
  - `approvalMode: "never"`에서도 `shell` 승인이 뜨는지 확인
  - 워크스페이스 **밖** 경로를 읽으라고 요청 → Rust 레이어에서 거부되는지 확인
  - 도구가 큰 출력을 뱉을 때 절단되고 절단 표시가 뜨는지 확인
  - 스트리밍 중 메시지 입력 → 현재 턴 종료 후 주입(steering)
  - 스트리밍/도구 실행 중 "중지" → 즉시 멈춤. 승인 대기 중 "중지" → 멈추지 않고 정상 종료
  - Mermaid/Recharts 시각화 렌더링 + 문법 오류 시 폴백
  - 앱 재시작 후 탭/대화 복원 (스트리밍 도중 강제 종료 시 마지막 완료 턴까지 복원되는지 — 의도된 동작)
  - Ollama 서버 다운 상태에서의 자동 재시도 → 에러 배너 → 복구 후 재시도 성공
- **확인 방법**: 체크리스트의 모든 항목이 통과해야 Phase 7 완료로 간주.
