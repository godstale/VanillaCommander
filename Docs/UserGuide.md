# Vanilla Commander 사용자 가이드 (User Guide)

Vanilla Commander는 **로컬 LLM 에이전트를 결합해 채팅으로 제어하는 파일 커맨더 앱**입니다. 파일 정리·문서 확인·지식 축적·반복 작업을 로컬 환경에서 수행하며, 외부 전송이 필요한 기능(클라우드·외부 에이전트)은 항상 동의를 먼저 받습니다.

---

## 1. 시작하기

### 1.1 사전 요구사항
1. **Ollama 설치**: [ollama.com](https://ollama.com)에서 Ollama를 설치하고 실행합니다.
2. **로컬 모델 준비**: 터미널에서 권장 모델을 다운로드합니다.
   ```bash
   ollama run qwen3.5:9b
   # 또는
   ollama run llama3.1:8b
   ```
3. **첫 실행**: 앱을 실행하면 6단계 셋업 위저드가 뜨고, Ollama가 켜져 있으면 모델 목록을 자동으로 불러와 기본 에이전트를 채워줍니다.

---

## 2. 화면 구성

- 좌측 ActivityBar: **파일 탐색기 · 채팅 · 에이전트 · 위키 · 매크로** (+ 최하단 설정).
- 시작 화면은 **파일 탐색기 탭**입니다. 탭 복원 시 삭제된 구 탭 타입은 조용히 버려집니다.
- 하단 **StatusBar**: 에이전트 상태 · 백그라운드 작업 · 위키 감시 · 현재 탭 정보 · 클립보드 · 일시 메시지.

### 2.1 파일 탐색기
- 상세 목록(정렬·다중 선택·키보드 탐색), 브레드크럼 주소창, 즐겨찾기·시스템 폴더, 분할 보기.
- 단축키: `Enter` 열기, `Backspace` 상위, `F2` 이름 바꾸기, `F3` 속성, `F4` 압축하기, `F5` 새로고침, `F6` 이동, `F7` 새 폴더, `F9` 이미지 앨범, `Del` 휴지통, `Shift+Del` 영구 삭제, `Ctrl+C/X/V`, `Ctrl+F` 찾기, `Alt+Enter` 정보, `Alt+D` 주소 직접 입력, `Alt+C` 에이전트 채팅.
- 툴바: `Alt+H` 숨김 표시, `Alt+B` 폴더 트리, `Alt+1/2/3` 1·가로2·세로2 분할.
- 이미지 앨범(`F9`): 폴더와 이미지만 썸네일 격자로 보여준다. 방향키는 격자 방향대로(상·하는 한 행씩, 좌·우는 한 칸씩) 보이는 항목만 이동한다. 더블클릭·`Enter`로 폴더 이동·이미지 뷰어 열기 동작은 목록과 동일하다.
- 앱 전용 단축키는 `Alt` 조합으로 통일한다 (브라우저 공통 키와 충돌 방지). `Alt`를 누르면 각 버튼에 가이드 배지가 표시된다 (배지는 버튼 안쪽 우하단): Alt 조합은 키만(`R`), `Ctrl`/`Shift` 조합은 전체(`Ctrl+F`)를 표시한다. Alt를 누른 채 조합 키를 누르면 바로 실행된다.
- 탭 헤더: `Alt+T` 새 탐색기, `Ctrl+Shift+H` 우측 분할, `Ctrl+Shift+V` 하단 분할 (`Alt+H` 숨김 토글과 겹치므로 분할만 Shift 조합 유지).
- 사이드 메뉴: `Alt+A/S/G/F/M` (탐색기 · 대화 목록 · 에이전트 · 위키 · 매크로, `Alt+D` 주소 입력과 겹치지 않도록 조정).
- 분할 창 전환: `Tab` (다음 창, `Shift+Tab` 이전 창, 분할 상태에서만). 분할이 바뀌면 활성 창 컨테이너로 포커스가 옮겨지므로 주소 입력창에 갇혀 단축키가 먹지 않게 된다.
- 채팅 도크를 열면 채팅 입력창에 자동으로 포커스가 간다.
- 탐색기 하단 상태바 좌측에는 백그라운드 에이전트 실행·진행 중 작업·실패가 표시된다. 평상시에는 `F2` 이름 바꾸기 · `F3` 속성 단축키 안내가 표시된다.
- 하단 1줄 채팅에 "`@보고서.pdf` 요약해서 같은 폴더에 md로 저장"처럼 지시하면 현재 위치·선택이 자동 첨부됩니다.

## 3. 대화 및 인터랙션 (Chat UX)

### 3.1 스트리밍 및 방향 전환 (Steering)
- 에이전트가 답변이나 도구를 연속적으로 실행하는 도중에도 입력창에 추가 지시를 타이핑하고 `Enter`를 누르면, 현재 작업이 끝난 직후 해당 지시가 즉시 주입(Steering)되어 방향을 조정합니다.
- 오른쪽 하단의 빨간색 **중지(Square)** 버튼을 누르면 언제든지 생성을 즉시 중단할 수 있습니다.

### 3.2 인라인 시각화 렌더링
- 에이전트 답변에 다이어그램이나 차트가 포함되면 별도 도구 없이 인라인으로 즉시 렌더링됩니다:
  - **Mermaid 다이어그램**: 플로우차트, 시퀀스, 클래스 다이어그램, 아키텍처 등을 SVG로 렌더링.
  - **Recharts 데이터 차트**: 수치 통계나 추이를 막대(Bar), 꺾은선(Line), 영역(Area), 원형(Pie) 차트로 렌더링.
  - 문법 오류가 발생할 경우 앱이 크래시되지 않고 원본 코드가 안전하게 폴백 표시됩니다.

## 4. 보안 및 사람의 승인 (HITL Approval)

Vanilla Commander는 사용자 조작과 에이전트 조작을 분리한 2단계 경계로 안전한 작업을 보장합니다:
1. **사용자 파일 작업**: 탐색기 UI 조작은 OS 권한 내 전체 허용. 시스템 폴더 쓰기는 경고 표시.
2. **에이전트 허용 루트**: 에이전트 도구는 작업 폴더 + 탐색기 탭 경로 + `@` 참조 + 등록 폴더 안에서만 동작.
3. **도구 승인 정책 (HITL)**:
   - **위험 도구만 승인 요청 (기본값)**: 파일 쓰기/수정(`write`, `edit`)·이동·삭제 및 셸 명령 실행(`shell`) 시 승인 대화상자가 팝업됩니다.
   - **모든 도구 승인 요청**: 읽기 전용 작업을 포함한 모든 도구 호출에 승인을 요구합니다.
   - **자동 승인 (위험)**: 파일 쓰기/수정을 즉시 실행합니다.
   - ⚠️ **셸(`shell`) 도구는 어떠한 승인 모드에서도 항상 실행 전 명령 전문과 함께 승인을 요구합니다.**
   - 에이전트가 수정/삭제/이동하는 파일은 실행 직전 작업 폴더 `backup/`에 스냅샷됩니다.

## 5. 에이전트 관리

- 좌측 액티비티 바에서 **에이전트(Bot)** 아이콘을 클릭하여 에이전트 관리 패널을 엽니다.
- 카드에는 이름·모델명·컨텍스트만 표시되며, 버튼은 **대화 시작·수정**입니다.
- **새 에이전트 생성**: 이름·설명, LLM 프로바이더(로컬/클라우드/외부 에이전트), 모델, 비전 지원, 그 밖에는 `▸ 고급 설정`(시스템 프롬프트·생성 옵션·승인·도구·스킬)을 조정합니다.
- **채팅 귀속**: 각 채팅은 하나의 에이전트 설정에 귀속됩니다. 기본 에이전트에 연결할 수 없으면 폴백 다이얼로그가 대체 에이전트를 제안합니다 (이번 세션에만 적용).

---

## 6. 에이전트 스킬 (Agent Skills)

- [Agent Skills 오픈 표준](https://agentskills.io)을 준수합니다.
- 워크스페이스의 `.agents/skills/<스킬명>/SKILL.md` 또는 전역 스킬 폴더에 마크다운 문서를 추가하면 에이전트가 이를 스캔합니다.
- **프로그레시브 디스클로저**: 평소에는 스킬의 이름과 한 줄 설명만 컨텍스트에 포함되며, 모델이 관련 작업이라고 판단할 때 본문을 동적으로 로드합니다.
- **수동 스킬 호출**: 채팅창에 `/skill:<이름> [추가 내용]`을 입력하면 즉시 해당 스킬 본문을 대화에 주입할 수 있습니다.

| **Alt + T** | 새 탐색기 탭 열기 |

| **Ctrl + Shift + H** / **Ctrl + Shift + V** | 활성 탭 우측 / 하단 분할 |
| **F5** | 탐색기 새로고침 |
| **F2** / **F3** | 이름 바꾸기 / 속성 (탐색기 상태바 좌측에도 평상시 안내) |

| **F9** | 이미지 앨범 보기 전환 |
| **Alt + H** / **Alt + B** | 탐색기 숨김 표시 / 폴더 트리 |
| **Alt + 1 / 2 / 3** | 탐색기 1분할 / 가로 2분할 / 세로 2분할 |
| **Tab** / **Shift + Tab** | 분할 창 전환 (다음 / 이전, 분할 상태에서만) |
| **Alt + D** | 탐색기 주소 직접 입력 |
| **Alt + C** | 탐색기 에이전트 채팅 도크 토글 |

| **Shift + Enter** | 메시지 줄바꿈 |
| **/compact** | 현재 대화 기록 수동 요약 및 컨텍스트 압축 |

## 8. 위키 · 매크로

### 8.1 위키 자동 등록

1. 위키 설정에서 감시를 켜고 감시 폴더(기본: OS 다운로드 폴더)를 확인합니다.
2. 새 파일이 들어오면 내용 추출 → LLM 1회 분류(날짜/순번/빈도) → `wiki/` 등록 + 원본 보관 폴더 이동이 자동으로 일어납니다.
3. 이미지는 비전 지원 에이전트가, 스캔 PDF는 OCR 외부 파서 또는 비전 에이전트가 필요합니다. 없으면 대기 목록에 남습니다.
4. 위키 패널에서 대기열·최근 처리·페이지 목록을 보고, 페이지를 클릭하면 바로 열립니다.

### 8.2 매크로 실행·스케줄

1. 채팅의 저장 버튼으로 현재 대화의 사용자 프롬프트를 매크로로 저장합니다.
2. 매크로 패널에서 [실행]하면 전용 대화에서 순서대로 실행되고, 편집 탭에서 순서·에이전트·스케줄을 바꿀 수 있습니다.
3. 스케줄(간격/매일/매주)을 걸면 앱 실행 중에 자동 실행됩니다. 승인 필요 도구가 나오면 멈춰서 확인을 요청합니다.
