
React + tauri 데스크탑 앱을 만들려고 한다. 이 앱은 ollama + 로컬 llm 을 이용해서 다양한 문서 및 비지니스 로직을 작성하고 이를 시각화 하는 기능을 제공하려고 한다.
ollama + local LLM 제공을 위해서 langchain/langgraph 또는 이와 유사한 도구(프레임워크)를 사용하려고 한다. 이 앱의 이름을 Fortress 라고 부르겠다.
아래 요구사항을 구현하려고 할 때 가장 효과적으로 구현할 수 있는 방법은 무엇일지 알려줘. 그리고 수정, 보완해야 할 부분이 있는지 알려줘. 필요하다면 나와 인터뷰를 진행하면서 요구사항을 명확하고 상세하게 정의하자.
- 로컬 LLM 사용을 위한 Agent 구현을 위해 Typescript(Javascript) 또는 python 기반 언어와 framework 를 사용한다.
- 일반적인 AI Agent 와 같이 AGENTS.md 파일을 인식하고 .agents/skills 폴더에 있는 skill 들을 도구로 인식할 수 있어야 한다.
- 기본으로 로컬 파일 컨트롤, 파일 저장/로드, 웹 검색을 위한 도구를 제공한다.
- 채팅창 세션동안 QnA 히스토리를 저장해야 한다.
- context size 를 지정할 수 있어야 하고 context size 가 75% 를 넘은 경우 자동 압축을 해야한다.
- 이 외에도 일반적인 Agent 앱이 제공하는 기본 기능들이 있다면 구현을 고려해야 한다. 

언어 스택 확정:
TypeScript(LangChain.js / LangGraph.js) 기반의 단일 스택

추가 고려사항: (선택사항)

답변해 주신 요구사항을 바탕으로 AgentFlow(AF)의 기능 명세서(PRD) 및 스킬 샌드박스 설계안을 정리했습니다.

Tauri(Rust)와 React, 그리고 LangGraph.js(TypeScript)를 결합하여 안정성과 확장성을 모두 확보할 수 있는 구체적인 아키텍처 및 구현 가이드입니다.

## 1. 시스템 아키텍처 개요

Tauri의 Rust 코어는 앱 실행 제어 및 OS 레벨의 안전한 파일 접근/샌드박스 역할을 담당하며, React + LangGraph.js 프런트엔드는 LLM 에이전트 루프와 UI 렌더링을 직접 처리합니다.

```
┌─────────────────────────────────────────────────────────────────┐
│ React Frontend (TypeScript)                                      │
│  ├─ UI: Chat / Visualizer (Mermaid.js / Recharts)               │
│  ├─ Core Engine: LangGraph.js State Graph                        │
│  └─ Skill Loader: Parse AGENTS.md & .agents/skills/             │
└────────────────┬────────────────────────────────────────────────┘
                 │ IPC (Tauri Command / Events API)
┌────────────────┴────────────────────────────────────────────────┐
│ Tauri Core (Rust)                                               │
│  ├─ Local File Scope Sandbox Access                             │
│  ├─ QuickJS/V8 Engine Sandbox (JS Skill Execution)              │
│  └─ SQLite Storage (Session History & Vector Store)             │
└────────────────┬────────────────────────────────────────────────┘
                 │ HTTP (Stream)
┌────────────────┴────────────────────────────────────────────────┐
│ Ollama Service (Local Port 11434)                               │
└─────────────────────────────────────────────────────────────────┘

```

## 2. 상세 기능 명세서 (PRD)

### 2.1 AGENTS.md 및 `.agents/skills` 파싱 & 로드

* **로드 방식:** 앱 스타트업 시 작업 디렉터리 내 `AGENTS.md` 파일과 `.agents/skills/` 폴더 스캔.
* **Skill 규격 (혼합 형태):**
* **프롬프트 기반 (`.md`):** System Prompt에 등록되는 자연어 지침 스킬.
* **코드 기반 (`.ts` / `.js` / `.json`):** LangGraph.js의 `DynamicTool` 규격으로 변환되는 직접 실행형 도구.


* **동적 툴 생성:** 파싱된 스킬을 LangGraph.js의 Agent State Node에 `tools` 배열로 주입.

### 2.2 기본 도구 (Built-in Tools)

1. **File System Tool:** 작업 디렉터리 내 파일 읽기/쓰기/목록 조회 (Tauri Scope API 바인딩).
2. **Web Search Tool:** 웹 검색 도구. 외부 API 를 사용하기보다 직접 google 등을 검색해서 결과를 파싱할 수 있는 도구를 만든다.
3. **Visualization Tool:** Mermaid.js 및 Recharts용 JSON/DSL을 생성하는 구조화된 출력(Structured Output) 전용 도구.

### 2.3 세션 관리 및 Context Auto-Compression (75% Threshold)

* **세션 저장:** SQLite(`tauri-plugin-sql`)에 QnA 메시지와 State Graph의 Checkpoint 저장.
* **토큰 임계값 모니터링:**
* Ollama `/api/show` 또는 `tiktoken` 기반으로 현재 대화 Context의 토큰 수 계산.
* 설정된 Context Window(예: 8,192 토큰)의 **75% 초과 시 자동 트리거**.


* **압축 전략 (LangGraph Summarizer Node):**
```typescript
// Context가 75%를 초과하면 대화 기록을 요약 노드로 전달
if (currentTokens > maxContextSize * 0.75) {
  const summary = await summarizeHistory(messages.slice(0, -2));
  // 요약본 + 최근 2개 대화 메시지로 State 업데이트
}

```



### 2.4 시각화 렌더링 엔진

* **Markdown Output Parser:** LLM 응답 중 `mermaid 코드 블록은 `<MermaidViewer />` 컴포넌트로, `recharts 코드 블록은 `<RechartsViewer />` 컴포넌트로 자동 파싱하여 인라인 렌더링.

## 3. Human-In-The-Loop (사용자 승인 모드) 설계

LangGraph.js의 `interrupt` 기능을 활용하여 에이전트가 위험한 동작(파일 삭제, 스크립트 실행, 외부 API 요청)을 실행하기 전에 실행을 일시 중단하고 사용자의 확인을 받습니다.

```
LLM -> Tool Call 결정 -> [Interrupt / Pause] -> UI 승인 팝업 
                                                  ├─ [승인] -> Rust Sandbox 실행 -> LLM 전달
                                                  └─ [거절] -> 거절 사유 -> LLM 전달

```

---

## 4. 스킬 실행 샌드박스 (Skill Sandbox) 설계안

TypeScript 코드 형태의 스킬을 메인 스레드나 OS 레벨에서 직접 실행할 경우 보안 위험이 있습니다.

### 샌드박스 구조 (3단계 안전망)

| 레이어 | 적용 기술 | 역할 및 안전 조치 |
| --- | --- | --- |
| **Layer 1: Runtime** | QuickJS (via Rust) | Node.js native API(process, child_process) 접근을 차단한 격리된 JS 엔진에서 스킬 실행. |
| **Layer 2: OS / FS** | Tauri File Scope | Rust 영역에서 앱 허용 폴더 외 파일 시스템 액세스를 물리적으로 차단. |
| **Layer 3: Human Guard** | LangGraph Interrupt | 코드 execution 스킬 호출 시 UI상에 사전에 위험도 평가 수치 및 코드를 보여주고 승인 유도. |

---

## 5. 단계별 구현 로드맵

1. **1단계 (기본 골격):** React + Tauri + LangGraph.js 보일러플레이트 구성 및 Ollama 로컬 연결 확인.
2. **2단계 (AGENTS & Skills):** `AGENTS.md` 파싱 및 `.agents/skills` 내 프롬프트/코드 스킬의 Dynamic Tool 등록 구현.
3. **3단계 (Context 압축 & 저장):** SQLite 세션 저장 및 75% 토큰 임계값 초과 시 요약(Summarize) 노드 동작 구현.
4. **4단계 (시각화 & HITL):** Mermaid/Recharts 렌더러 구현 및 `interrupt` 기반 사용자 승인 모드 UI 통합.
